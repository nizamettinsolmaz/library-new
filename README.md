# Library Management System (Python OOP)

## 📌 Project Overview
This is a Python-based application that demonstrates the core principles of **Object-Oriented Programming (OOP)**, such as Inheritance, Encapsulation, and Abstraction. I developed this system to manage library operations, including book tracking, librarian roles, and patron management.

## 🛡️ Relation to Cybersecurity
Understanding how data structures and classes interact is fundamental for:
- **Application Security:** Analyzing how objects handle data to prevent unauthorized access.
- **Access Control:** Implementing logic similar to "Librarian vs. Patron" roles, which is the basis of Role-Based Access Control (RBAC).
- **Automation:** Writing clean, modular scripts for security auditing.

## 🚀 Features
- **Class-Based Architecture:** Modular design with `Book`, `Library`, and `Librarian` classes.
- **Inheritance:** The `Librarian` class inherits from a base `Person` class, showcasing a clear hierarchy.
- **Management Logic:** Functions to add books, register patrons, and list library inventory.

## 🛠️ Technical Stack
- **Language:** Python 3.x
- **Concepts:** OOP, List Management, Class Methods
